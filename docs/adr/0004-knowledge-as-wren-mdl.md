# Knowledge 以 Wren MDL 表示，MongoDB 專屬資訊放 mqlc 命名空間

Profile 的結果和人工補寫的定義都存成 Wren MDL 專案（models、relationships、instructions），而不是自訂格式。MDL 已經是給 LLM 讀的語意層格式，人工可以直接編輯，也能和 Wren 生態互通；代價是它源自關聯式模型，表達不了巢狀路徑、陣列、嵌入文件。這些資訊放在 model / column properties 的 `mqlc` 命名空間（例如 `mqlc.path`、`mqlc.array`、`mqlc.embedded`），檔案仍是合法的 MDL。

一個資料庫的 MDL 專案是一個目錄：`mdl.json` 是 Wren MDL（`catalog`、`schema`、`models`、`relationships`；Wren 沒有 MongoDB 的 `dataSource`，所以不寫），`instructions.json` 是 WrenAI 形狀的 instruction 清單（`[{"instruction": ...}]`），因為 Wren 的 MDL schema 不允許頂層多出其他欄位。每個 collection 是一個 model，每個欄位路徑是一個 column（`name` 是點分隔的路徑）。Wren 規定 column properties 的值只能是字串，所以布林與數字也寫成字串：`mqlc.path`、`mqlc.presence`（`出現次數/外層文件數`，外層文件是 collection 的文件、嵌入文件或陣列元素；存次數而不是四捨五入的比例，才不會把很少見或幾乎都有的欄位寫成 0% 或 100%）、`mqlc.types`（各 BSON 型別的次數）、`mqlc.array`、`mqlc.elementTypes`、`mqlc.embedded`、`mqlc.inArray`（最內層的外圍陣列路徑）。Column 的 `notNull` 表示每份抽樣文件都有這個欄位且不為 null：外層欄位可能缺少或為 null、或欄位在陣列元素裡（陣列可能是空的）時都是 false。值域也是 column properties（#9 起）：`mqlc.distinct`（相異值數，超過 10,000 寫成 `>10000`）；至多 20 個相異值且都不是 ObjectId、Date 或超過 40 字元的字串時，`mqlc.enum` 列出全部值（JSON 陣列，次數多的在前）；否則給 `mqlc.topValues`（出現超過一次的值中最常見的 5 個，`[[值, 次數], ...]`）、數值與日期的 `mqlc.min` / `mqlc.max`（JSON），以及至少 90% 的值是完整符合的字串時，該 regex 形狀為 `mqlc.format`。陣列的值是它的元素。參照寫成 MDL `relationships`：先找名稱對得上的 collection（`accountId`、`account_id`、`account.id` → `accounts`；只是自身 collection 名稱的鍵，例如 `customers.customerId`，是 `_id` 的副本，不算），對不上時 ObjectId 欄位再試每個 `_id` 為 ObjectId 的 collection；都要欄位最先出現的 100 個相異字串、整數或 ObjectId 值有九成是對方的 `_id`。Join type 依樣本判斷：欄位在陣列裡或本身是陣列為 MANY_TO_MANY，抽樣值都不重複為 ONE_TO_ONE，否則 MANY_TO_ONE。Relationship 的 properties 記 `mqlc.path`（參照欄位的路徑）與 `mqlc.matched`。被排除的敏感欄位在 find 的 projection 就擋掉，值不離開 MongoDB，MDL 只在 model 的 `mqlc.excluded` 留下路徑；排除一個不存在的欄位是錯誤，因為那多半是打錯字，而打錯字會讓欄位漏出去。Model properties 可以是任意 JSON：`mqlc.sampled`、`mqlc.documents`、`mqlc.excluded`。放進 prompt 時，MDL 以官方說明的版面 render（每個 collection 一行 `Collection: <name>`，每個欄位一行 JSON），讓 arm 之間只差內容、不差形狀；欄位行依序帶 `in_array`、`present`、`references`（參照欄位不列值，id 不提供對方沒有的資訊），再帶 `values`，或 `format`、`min`、`max`、`common_values`（不含次數）。
